⚠️ 致命陷阱條款避雷指南

1. 百貨統收機台陷阱：
若松本清、UNIQLO、BicCamera 位於大丸、高島屋、Lumine、OIOI 或機場免稅店等百貨商場內，簽單 MCC Code 往往是百貨公司，玉山熊本熊加碼會全部失效！此時應果斷刷 富邦 J 卡 (6%) 或 Costco (5%)。

2. 富邦 J 卡滿千門檻：
富邦 J 卡日韓加碼需要「單筆滿新台幣 1,000 元」(約 4,830 日圓)。若單筆未達千元，請改刷 Costco 聯名卡 (無低消限制享 5%)。

3. PayPay 掃碼秘訣：
很多日本微型店家/居酒屋不收信用卡只收 PayPay。打開玉山 Wallet 掃 PayPay 享有免 1.5% 手續費與回饋；若加碼額度已滿，可切換扣外幣日幣帳戶。
